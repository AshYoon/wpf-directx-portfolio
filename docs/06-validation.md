매 프레임 이동·재구성 뒤 검색 1회를 수행하는 실시간 화면은 다른 작업 부하입니다.

중앙 밀집 배치도 검색 중심을 월드 전역에 분산했으므로 최악의 경우를 대표하지 않습니다.
최악의 조건을 보려면 화면에서 중앙 밀집을 선택하고 중앙의 반경을 크게 늘려 비교할 수 있습니다.

위 수치는 독립 데모의 CPU 검색 비용이며 회사 프로젝트의 20→60FPS 성과와 연결된 재현 수치가 아닙니다.
